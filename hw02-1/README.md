## 方法要点
- 收益率使用 `Dretwd`（考虑现金红利再投资），不复权价 `Clsprc` 只用于作图与核对；
- 停牌从交易日历缺口推断（共 3 段、21 个股票-日）：持仓期计算中停牌日收益为 0，单日统计剔除 3 个复牌日（多日累计收益）；
- 等权组合：每日目标权重 0.1；市值加权组合：$w_{i,t-1}=MV_{i,t-1}/\sum MV_{j,t-1}$；每日按目标权重计算收益、忽略交易成本（官方教学设定）；
- 几何年化收益、日收益样本标准差 × √252、净值相对历史峰值的最大回撤（非负）。

## 预期主要输出（运行后生成于 `outputs/`）
- `figures/`：fig1 不复权收盘价、fig2 净值曲线、fig3 日收益、fig4 20 日滚动波动、fig5 相关热力图、fig6 市值权重、fig7 组合净值与回撤
- `tables/`：选股表、描述统计、相关矩阵、组合绩效
- `qa/`：原始文件清单、停牌区间、极端收益

关键结果：等权组合期末净值 1.093（年化 1.63%，波动 17.54%，最大回撤 22.67%）；t−1 市值加权组合 1.030（0.54%，18.63%，35.68%）。
