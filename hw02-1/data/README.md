# HW02-1 数据获取说明（仅限中山大学 CSMAR 授权用户）

CSMAR 数据受数据库授权限制，本仓库**不提供**原始数据。请登录 CSMAR（校园网或学校 VPN），按下表导出 CSV 格式的压缩包，**保持 CSMAR 默认的 ZIP 文件名、不要解压**，放在本目录下的 `raw/` 中：

```
hw02-1/data/raw/
├── 日个股回报率文件231556970仅供中山大学使用.zip
├── 日个股回报率文件231827931仅供中山大学使用.zip
└── 上市公司基本信息年度表175941816仅供中山大学使用.zip
```

| 表 | 代码 | 筛选条件 | 字段 |
|---|---|---|---|
| 日个股回报率文件 | `TRD_Dalyr` | 证券代码：600519, 600036, 601318, 600900, 601088, 601668, 600050, 601111, 000002, 002714；交易日期 2020-12-01—2026-09-16（本作业分两次导出：2020-12-01—2025-11-28 与 2025-12-01—2026-09-16，两次都可以） | Stkcd, Trddt, Clsprc, Dnshrtrd, Dnvaltrd, Dsmvtll, Dretwd, Dretnd |
| 上市公司基本信息年度表 | `STK_LISTEDCOINFOANL` | 统计截止日期 2005—2015（与 HW02-2 共用同一文件） | Symbol, ShortName, EndDate, ListedCoID, IndustryNameC, IndustryCodeC, FullName, LISTINGDATE |

说明：
- 导出编号（如 231556970）由 CSMAR 自动生成，每次导出都不同。Notebook 按文件名前缀匹配（`日个股回报率文件*.zip`、`上市公司基本信息年度表*.zip`），**所以编号不同也能运行**；但 `日个股回报率文件*.zip` 必须覆盖上述完整日期区间，且不能重叠。
- 每个 ZIP 内应包含 `TRD_Dalyr.csv`（或 `STK_LISTEDCOINFOANL.csv`）以及 `[DES][csv].txt` 字段说明。
- 请勿把这些文件上传到公开仓库或公开网盘。
