## 方法要点
- 逐年的历史口径：当年行业代码 K70（证监会 2012 版）、年末已上市、年末未终止上市；非平衡面板共 1,193 个公司-年、172 家公司；
- 产权按当年实际控制人性质分为国企、民营、其他（外资、其他、多值组合）、产权不明（缺失）四类；
- 六项指标按官方公式计算，ROA/ROE 使用平均余额，2004 年资产负债表只作 2005 年的期初值；借款缺失不补 0；平均权益 ≤ 0 时 ROE 设为缺失；
- bankloan 用 CSMAR 的“短期借款 + 长期借款”作代理，其中包括其他金融机构的借款，但不包括一年内到期的长期借款；
- 离群值：主结果保留原始值，同时报告均值与中位数，另做 1%/99% 缩尾敏感性分析；
- `STK_ITEMCHANGE.csv` 的备注字段含未转义引号与嵌入换行，Notebook 按记录锚点逐条解析并验证，1,302 条记录无一丢失。
